# How to Contribute

Thanks for your interest in contributing to Catalyst Center MCP Open Source! 

Please note that all of your interactions in the project are subject to our
[Code of Conduct](/CODE_OF_CONDUCT.md). This includes creation of issues or pull
requests, commenting on issues or pull requests, and extends to all interactions
in any real-time space e.g., Slack, Discord, etc.

This project does not currently accept contributions.  We invite community 
members to fork and experiment with the content and accept submission of 
issues.  

## Reporting Issues

**If you discover a security bug, please do not report it through GitHub.
Instead, please see security procedures in [SECURITY.md](/SECURITY.md).**

Before reporting a new issue, please ensure that the issue was not already
reported or fixed by searching through our [issues
list](https://github.com/cisco-en-programmability/catc-mcp-oss/issues).

When creating a new issue, please be sure to include a **title and clear
description**, as much relevant information as possible, and, if possible, a
test case.

While we welcome reporting any general issues identified, these issues 
will be addressed in a best effort manner and timeline by the project 
maintainers.
